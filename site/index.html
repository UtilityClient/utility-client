What it gives you

The parts that apply across the whole client, rather than a single module.

Keybind on every module

Click a module's key box, then press any keyboard key or mouse button. Works with your own keybinds, ignores held state while a menu is open, and is saved to your config.

Real colour picker

Every colour setting is a swatch you can open: a saturation and brightness square plus a hue slider, with drag support. No preset list, no typing hex codes by hand.

Config you control

Everything lives in a readable JSON file. The Configs tab can save, reload and reset back to defaults without hand-editing anything.

Rounded, consistent UI

One dark purple theme across the menu and the settings screens, with a scrollable settings list, live search and a moveable HUD.

Nothing server side

The mod installs on your client only. No packets are rewritten and no server install is needed, so it cannot break a world or a whitelist.

Bounded automation

Where a module repeats an input, it is capped and clearly labelled. Nothing trades or acts on its own without you being there.

Licence keys

How access to the client works, and what it does and does not protect you against.

How a key is used

Paste it into the activation screen with Insert or /utilitykey. The client then asks the key server whether it is valid, and caches the answer for six hours so it does not phone home on every launch.

You are offline-proof for 72 hours. If the key server is unreachable the client keeps running on your last verified check, so a server problem never locks you out of your own game.

Your profile card

The card at the bottom left of the menu shows your plan and how long is left on it. A green dot means the key is verified. Clicking the card takes you back to the activation screen to change or remove the key.

What a key does not stop

This is worth being blunt about. The mod runs on your own machine, so anyone determined can patch the check out of the jar. A key stops casual sharing and casual piracy, which is the overwhelming majority of it. It is not unbreakable DRM, and it should not be sold as though it is.

Installing

Client only. Nothing goes on the server.

Requirements

  • Minecraft 26.2
  • Fabric Loader 0.19.5 or newer
  • Fabric API 0.161.0+26.2
  • Java 25 or newer

Steps

  1. Install Fabric Loader and Fabric API for Minecraft 26.2.
  2. Drop utility-client-0.1.0.jar into your profile's mods folder.
  3. Launch Minecraft and press Insert. Paste your key when asked.

Controls

Getting around the menu.

Opening and toggling

  • InsertOpen the menu, or the key screen if unlicensed
  • /utilityOpen the menu from chat
  • /utilitykeyOpen the key screen directly
  • Left clickToggle a module card
  • Right clickOpen that module's settings
  • EscClose a menu

Inside a module's settings

  • ClickPick a value with the − and + buttons
  • ClickOpen the colour picker on a swatch
  • ClickStart listening, then press a key or mouse button
  • DeleteClear a keybind while listening
  • ScrollMove through a long settings list

Config file

Module states, every setting and every keybind are stored in config/utility-client.json. The Configs tab in the sidebar can save, reload or reset everything back to defaults.

What it deliberately does not do

Being clear about this up front saves everyone time.

✕Combat automation
✕X-ray or ore detection
✕Reach or aim assist
✕Packet spoofing
✕Anti-cheat bypasses
✕Automated mining or block automation

Where a module repeats an input for you, such as the click holder or the villager trader, it is capped, clearly labelled, and never acts on its own without you being there.
